# Project rules

- This repository is a personal, unpacked Chrome extension build. It is not published to the Chrome Web Store, and no GitHub releases or tags are created for it.
- Work only on this repository's own code. Do not merge, rebase onto, or otherwise sync the upstream repository.
- After source changes: run `npm run build`, reload the unpacked extension from `chrome://extensions`, then refresh X.
- Verify locally: typecheck, tests, package check, and the built extension in the local browser.
